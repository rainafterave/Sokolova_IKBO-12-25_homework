# Переводчик конфигураций, вариант 23

Домашняя работа по конфигурационному управлению, ИКБО-12-25.
Программа на Python 3.11+ разбирает учебный конфигурационный язык
специализированным анализатором Lark.

## Установка и тесты

Отдельная сборка не требуется. Из корня проекта установите зависимости.

```cmd
py -3 -m pip install -r requirements.txt
set "PYTHONPATH=src"
py -3 -m unittest discover -s src\tests -v
```

Грамматика находится в `src/grammar.lark`, разбор и проверка значений
в `src/language.py`. Поддерживаются десятичные числа, строки, вложенные
словари, комментарии и объявления `set NAME = значение`.
Постфиксные выражения `^(N 1 +)` вычисляются при переводе.
Операции `+`, `sqrt` и `pow` выполняются через стек в
`src/expressions.py`. Функции также принимаются как `sqrt()` и `pow()`.
