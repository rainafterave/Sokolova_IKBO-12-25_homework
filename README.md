# Переводчик конфигураций, вариант 23

Домашняя работа по конфигурационному управлению, ИКБО-12-25.
CLI-приложение на Python 3.11+ преобразует учебный конфигурационный
язык в JSON. Синтаксический анализ выполняет Lark по LALR-грамматике.
Вход поступает через стандартный ввод, путь к выходному файлу задаётся
ключом командной строки.

## Установка и запуск

Отдельная сборка не требуется. Из корня проекта установите зависимости.

```cmd
py -3 -m pip install -r requirements.txt
run.bat --output output\server.json < src\examples\server.conf
type output\server.json
```

В Git Bash или Linux можно использовать `run.sh`.

```bash
python -m pip install -r requirements.txt
bash run.sh -o output/server.json < src/examples/server.conf
```

Скрипты запуска принимают следующие параметры.

| Параметр | Назначение |
| --- | --- |
| `-o PATH`, `--output PATH` | Обязательный путь к JSON-файлу. Родительские папки создаются автоматически. |
| `-h`, `--help` | Справка по командной строке. |

Вход и выход используют UTF-8. Поддерживается входной файл с BOM.
Успешный запуск возвращает код 0, ошибка перевода или записи — 1,
ошибка аргументов — 2. Сообщения об ошибках идут в stderr.
Синтаксические ошибки содержат строку, столбец и фрагмент исходника.
JSON записывается после успешного вычисления всей конфигурации.
Замена файла выполняется атомарно, поэтому неудачный перевод сохраняет
предыдущий выходной файл.

## Синтаксис

Имена содержат только заглавные латинские буквы, например `PORT`.
Числа соответствуют `\d+\.\d*`, например `0.5` или `12.`.
Строки заключаются в двойные кавычки. Поддерживаются Unicode и
JSON-экранирование, например `\n` и `\"`.
Многострочный комментарий начинается с `#=` и заканчивается `=#`.

Словарь записывается между `begin` и `end`. Поля имеют вид
`NAME := значение;`. Значением может быть число, строка, вложенный
словарь или результат константного выражения.
Пустые словари допускаются, повторяющиеся ключи вызывают ошибку.

```text
set PORT = 8080.
set WORKERS = 4.
begin
  NAME := "Учебный сервер";
  NETWORK := begin
    PORT := ^(PORT);
  end;
  CONNECTIONS := ^(WORKERS 2 pow);
end
```

Объявление константы имеет вид `set NAME = значение`, без точки с
запятой. Константы объявляются перед корневым значением или между
полями словаря. Они вычисляются в порядке объявления и доступны в
последующем коде текущего словаря и вложенных словарях. Локальные
объявления не выходят за пределы своего словаря. Повторное объявление
доступного имени и обращение к неизвестной константе вызывают ошибку.
Константы могут хранить числа, строки и словари.

Выражения используют постфиксную форму `^(операнды операция)`.
Ссылка на константу без вычислений записывается как `^(NAME)`.
Допускаются вложенные выражения.

| Операция | Пример | Действие |
| --- | --- | --- |
| `+` | `^(2. 3. +)` | Сложить два числа. |
| `sqrt` или `sqrt()` | `^(9. sqrt)` | Извлечь квадратный корень. |
| `pow` или `pow()` | `^(2. 3. pow)` | Возвести первое число в степень второго. |

В примере задания встречается целое `1` внутри выражения.
Поэтому целые операнды допускаются внутри `^(...)`, а обычные
числовые значения требуют десятичной точки.
Для вызовов функций принимаются обе записи, поскольку в условии
они названы `sqrt()` и `pow()` без полного примера вызова.

## Как устроен переводчик

| Файл | Функции |
| --- | --- |
| `src/grammar.lark` | Правила Lark для всех конструкций языка, включая вложенность. |
| `src/language.py` | `parse` разбирает текст, `evaluate` вычисляет значение. `read_number` проверяет число, `declare` объявляет константу, `evaluate_dictionary` обрабатывает поля и локальную область, `evaluate_expression` исполняет постфиксную последовательность. |
| `src/expressions.py` | `apply_operation` снимает операнды со стека и кладёт результат. `finish_expression` проверяет, что осталось одно значение. |
| `src/errors.py` | `LanguageError` представляет ошибки языка и вычислений. |
| `src/json_output.py` | `write_json` сериализует результат и заменяет выходной файл. |
| `src/main.py` | `main` читает аргументы и stdin, запускает перевод и сообщает об ошибках. |

Операции проверяют число и тип операндов. Переполнение и
нечисловые аргументы вызывают ошибку. Используются конечные числа
Python `float`, поэтому десятичные дроби могут округляться при вычислениях.

## Три примера

В `src/examples` находятся конфигурации из разных предметных областей.

| Файл | Предметная область |
| --- | --- |
| `server.conf` | Веб-сервер, порт, рабочие процессы и соединения. |
| `education.conf` | Учебный курс, часы занятий и параметры группы. |
| `robot.conf` | Робот, площадь карты, сенсор и ограничение скорости. |

```cmd
run.bat -o output\server.json < src\examples\server.conf
run.bat -o output\education.json < src\examples\education.conf
run.bat -o output\robot.json < src\examples\robot.conf
```

## Тесты

Команды для Windows cmd.

```cmd
set "PYTHONPATH=src"
py -3 -m unittest discover -s src\tests -v
```

Команда для Git Bash или Linux.

```bash
PYTHONPATH=src python -m unittest discover -s src/tests -v
```

Тесты покрывают все конструкции, вложенные словари и выражения,
комментарии, константы разных типов и области видимости, синтаксические
ошибки и ошибки вычисления. CLI проверяется отдельными процессами
через stdin, включая сохранение старого файла при ошибках.

История разработки содержит этапы разбора языка, вычисления
констант и завершения CLI с примерами и проверками.
